# 0011 — Design values are Rust constants

Status: **accepted**, inherited from Malaysia. The original record, in Spanish, is
[Malaysia ADR 0011](https://github.com/HBlanqueto/malaysia/blob/7daea4b7e3e5f2d59c9bce62103b16e4e0d63de2/docs/decisiones/0011-valores-de-diseno-como-constantes-rust.md) in its history.

## What still holds

1. The design values are public compile-time constants of `ctdesign`, and
   `ctdesign` is the only crate that defines them.
2. A color that differs between the focused and unfocused window is a
   `FocusPair`.

## What changed

- The constants are generated by `crates/ctdesign/build.rs` from
  `tengen/tokens.json` and `tengen/components.json`
  ([0032](0032-neptunia-as-design-source.md), [0046](0046-tengen-visual-language.md)).
- An app can override any value at run time through styles; the defaults stay
  in `ctdesign` ([0064](0064-styles-and-themes.md)).
